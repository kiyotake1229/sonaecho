## 変更内容

- 提案書（文書版・ページ・PDF）
  - 差別化の1つ目を「必要量から逆算する」から「何日もつかと、次に何を買うかまで示す」に変更
  - 期限の登録（ボタン・まとめ登録・期限ごとの行）、備蓄の配分、紙に残す防災カードを追加
  - 表紙の数字を「3日→7日／120+／圏外OK」から「約1.5日／146／圏外OK」に。9/23 の改善点を表紙に並べた
  - 展開案の段階名を「v1.0 今回／v1.1」から「無料版（今回）／プラス（買い切り）」に変更（アプリの版 v1.1.0 と紛らわしいため）
  - デモの順番を「サンプル入りで開く → 何日もつか → 次にやること → 買い足し・期限順 → 配分と防災カード → 機内モード」に変更
  - 数字の食い違いを解消（プリセット「120種類以上」→146種類、チェック項目「60項目超」→基本61・最大80、そなえ度80「安心」→78「あと少し」）
- 話す台本: 準備チェックに「防災カードを1枚印刷して持っていく」「古い版が残っていないか確かめる」を追加。想定質問に「何日もつかの計算」を追加し、根拠を農水省の数字に合わせた
- 申請手順（App Store の説明文の下書き）: 何日もつか・次にやること・期限の入力・140種類以上・備蓄の配分・防災カード・元に戻すを追加。キーワードに「買い物リスト,防災カード」（80字）。写真への保存の説明と `NSPhotoLibraryAddUsageDescription`、iPad 用スクリーンショットの注意、英文の審査用メモを更新
- PDF は Chrome のヘッドレス印刷で作る。印刷では画面幅の判定が狭い側になるため、横並びを印刷用のスタイルで明示している
