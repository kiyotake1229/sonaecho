# ホームで「何日もつか」と「次にやること」を示す（そなえ帳）

- 管理番号: #0002
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-23
- 関連: #0001（現状の仕様と構成）、#0008（ボンベの目安の変更で必要量が変わる）

## 概要

ホームを「点数を見る画面」から「次に何をすればよいかがわかる画面」に変えた。いまの備蓄で何日すごせるか（水・食料・トイレのうち最初に尽きるもの）を大きく出し、そなえ度が上がる順に「次にやること」を並べる。足りない分は、何をいくつ買えばよいかを計算して、1タップで買い足しリストに入る。

## 対象ファイル

- `index.html`
  - 計算: `rate`（1日の必要量）・`lastDays`（何日もつか）・`ESSENTIAL`・`bottleneck`、`score`（行に `id`・`ratio`、戻り値に `wsum`・`capped`・`level` を追加）、`LEVELS`
  - ホーム: `renderHome`・`nextActions`・`buyPlan`・`DEFAULT_BUY`・`addPlans`・`openAddCat`・`startOwn`、内訳シート `sheetScore`
  - データ: `S.demo`（`DEF`・`loadDemo`・`finishOb`）
  - CSS: `.hero .big`・`.next`・`.demo-bar`・`.nbox`・`.days-list`・`.dl`

## 変更内容

- ホーム上部の一文を「4人 × 3日分の備え」から「いまの備蓄で 約1.5日」に変えた
  - 日数 = 備えている量（期限切れを除く）÷ 1日の必要量
  - 飲料水・主食・簡易トイレ（乳幼児がいればおむつも）のうち一番短いものを出し、「簡易トイレが先に尽きます」と添える
  - 0.1日未満は「0日」、10日以上は整数で表示する
- 次にやること（3件）を追加した
  - そなえ度が上がる点数（＋N点）の大きい順に並べる
  - 候補は次のとおり。足りない分類（買い足しリストへ）、明かり・救急・介護用品の用意、持ち出し袋のチェック、家族カード、集合場所
  - 期限が未登録の品があれば、上位3件に入らなくても4件目に「期限を登録する」を出す（#0003）
  - 買い足しリストにすでに入っている分類は、右の札をチェック印にし、タップでリストを開く
- 足りない分を何をいくつ買うかの計算（`buyPlan`）を追加した
  - 数 = 不足量 ÷ 1つあたりの量（切り上げ）
  - 品は、その分類で今いちばん多く持っている品（期限切れでないものを優先）。持っていなければ既定の品（水 2L・アルファ米・簡易トイレ・カセットボンベ・おむつ・ペットフード）
- 必要量のカードに「足りない分を買い足しリストへ（N品目）」を追加した。同じ名前の未購入の行があれば、数の多い方に合わせる。すべて入っていれば「買い足しリストを見る」になる
- 段階名を変えた
  - 60〜79点を「しっかり」から「あと少し」に変更
  - 飲料水・主食・簡易トイレ（乳幼児がいればおむつ）のどれかが目標未満のうちは、80点以上でも「あと少し」までにする。内訳シートにも注記を出す
- 内訳シートの先頭に「いまの備蓄で何日もつか」を分類ごとのバーで追加した
- そなえ度の計算を直した
  - 備蓄が0件のとき「期限管理」が満点になり、そなえ度が5点前後から始まっていた。0点にした
  - 明かり・救急・介護の「用意あり」は、数量0の品を数えない
- サンプルデータの表示中は、ホーム上部に帯を出す。「自分の記録を始める」で最初の設定に戻れる（撮影用の `shot=1` では出さない）

確認した内容（ローカルの Chrome、スマホ幅）:

- サンプル（4人・3日分）で「いまの備蓄で約1.5日」「簡易トイレが先に尽きます」、段階「あと少し」（78点）
- 次にやることが「飲料水をあと9L ＋7点」「簡易トイレをあと30回 ＋7点」「非常持ち出し袋をそろえる ＋5点」の順に出ること
- 1件目をタップすると「水 2L 5本」が買い足しリストに入り、札がチェック印に変わること。まとめて追加（3品目）と「元に戻す」
- v1.0 で保存したデータをそのまま開いて、表示が崩れないこと
- 初回設定から始めた2人世帯で「約1日」と、4件目の「期限を登録する（3点）」
