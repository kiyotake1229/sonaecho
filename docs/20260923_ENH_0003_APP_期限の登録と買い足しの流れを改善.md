# 期限の登録と買い足しの流れを改善（そなえ帳）

- 管理番号: #0003
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-23
- 関連: #0002（買い足しリストへの追加）、#0007（元に戻す）

## 概要

期限の管理はこのアプリの中心だが、初回設定で数だけ入れた品は期限が空のままで、1件ずつ編集するしかなかった。期限をまとめて登録できる画面と、入力を速くするボタンを追加した。また、買い足した分を同じ行に足すと古い分と新しい分の期限が混ざる問題を、期限違いの別の行（ロット）として登録する形に直した。

## 対象ファイル

- `index.html`
  - 期限: `needsExp`・`EXP_CATS`・`presetOf`、`sheetBulkExp`・`bxSet`・`bxNone`・`saveBulkExp`、入力画面 `sheetForm`（期限のボタン・`markQ`・`formNoExp`）・`saveForm`
  - 買い足し: `shopTarget`・`shopToStock`・`stockShop`・`formShopId`、`consume`
  - 一覧: `stockList`（`stockGroup`）・`stockExp`・`itemRow`・`sheetItem`
  - データ: 備蓄に `noExp`（期限なしと決めた印）、買い足しの行に `preset`
  - CSS: `.qchips`・`.qchip`・`.bx`・`.mini`・`.badge.unset`・`.item.zero`

## 変更内容

- 期限の入力欄の下に「今日から 半年／1年／2年／3年／5年」のボタンを追加。押すと日付が入り、選んだボタンが強調される
- 「期限未登録」の札を追加した。対象は、期限が空・期限なしと決めていない・残りがある品のうち、プリセットに保存期間があるもの（自作の品は水・食料・救急・乳幼児・ペットの分類）
- 期限をまとめて登録するシートを追加した
  - 品ごとに日付欄と「今日から 1年／3年／5年」「期限なし」のボタン
  - 「期限なし」にした品は、次から聞かない（`noExp`）。入力画面で「なし」を押して保存した品も同じ
  - 入口はホームの「次にやること」と、備蓄の期限順の上部
- 期限順の一覧に「期限が未登録」の区分を追加し、「期限なし」と分けた
- 買い足しリストの「備蓄へ」を変えた
  - 紐づく品に残りがあり、期限も入っているときは、新しい行として登録する。期限はプリセットの目安を入れ、画面に「今ある分と期限が違うので、別の行として登録します」と出す
  - 残りが0なら同じ行に数を足し、期限を新しくする
  - 期限を入れていない品は、数だけ足す
  - 紐づく品がなくても、名前がプリセットと同じ行（例: 乾電池 単1）は「備蓄へ」でプリセットから登録できる
- 不具合修正: 「備蓄へ」を開いて保存せずに閉じても、行が「買った」になっていた。保存したときだけ「買った」にする
- 「1つ使った」で行が0になり、同じ品の別の行（期限違い）が残っていれば、0の行を片付け、買い足しリストの紐づけを残った行に付け替える
- 一覧を変えた
  - 並びを「分類 → 名前 → 期限の早い順」にした（同じ品の行が隣に並ぶ）
  - 「分類ごと／置き場所ごと」の切り替えを追加
  - 数量0の行は薄く表示する
- 品の詳細に「同じ品がほかにN件あります（期限が違う分）」を表示する
