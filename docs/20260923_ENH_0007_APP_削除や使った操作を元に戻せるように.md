# 削除や「使った」を元に戻せるように（そなえ帳）

- 管理番号: #0007
- 種類: ENH（機能改善）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-23
- 関連: #0002（買い足しリストへの追加）、#0003（使いきった行の片付け）

## 概要

備蓄の削除・家族カードの削除・「1つ使った」・買い足しリストの操作のあと、5秒間「元に戻す」を押せるようにした。1件ずつの削除では確認のダイアログを出さず、あとから戻せる形にした。全データの削除・メモの全消去・バックアップからの復元・サンプルでの上書きは、これまでどおり確認する。

## 対象ファイル

- `index.html` … `toast`（3つ目の引数 `undo`）・`snap`、`delItem`・`delFamily`・`consume`・`addPlans`・`delShop`・`clearShopDone`・`delCustom`、CSS `.toast.act`・`.toast .tu`

## 変更内容

- 操作の直前の状態を丸ごと文字列で覚え、「元に戻す」でその状態に戻して保存し直す
- 戻したあとに開き直す画面を指定できる（家族カードの一覧・チェックリスト）
- 対象の操作: 備蓄の削除、家族カードの削除（確認ダイアログから変更）、1つ使った、買い足しリストへの追加・行の削除・「買ったものをまとめて消す」、チェックリストの自分の項目の削除
