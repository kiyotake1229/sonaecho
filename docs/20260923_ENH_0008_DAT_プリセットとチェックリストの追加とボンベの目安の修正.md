# プリセットとチェックリストの追加、ボンベの目安の修正（そなえ帳）

- 管理番号: #0008
- 種類: ENH（機能改善）
- 対象: データ（DAT）
- 作成日: 2026-09-23
- 関連: #0001（「120種類以上」の表記と実装94件の食い違い、世帯別の項目が持ち出し袋にしかない点）

## 概要

備蓄のプリセットを94件から146件に増やし、チェックリストの4つすべてに世帯別（乳幼児・高齢者・ペット）の項目を加えた。あわせて、カセットボンベの必要量を農林水産省の目安（1人1週間 約6本）に合わせた。従来は1人1日0.5本（1週間で3.5本）で、目安より少なかった。

## 対象ファイル

- `index.html` … `CATS`（必要量の式を `target`・`who`・`ceil` で持つ形に変更）、`PRESETS`、`CHECKLISTS`、`TIPS`

## 変更内容

- 必要量の式を「1人1日の目安 `target` × 数（人数・乳幼児・ペット）× 目標日数」に統一した
  - カセットボンベは 6/7本（1人1日）で、切り上げる。4人・3日分は6本 → 11本、4人・1週間分は14本 → 24本
  - 出典: 農林水産省「災害時に備えた食品ストックガイド」。1人1週間当たりカセットボンベ約6本。ボンベの使用期限は約7年、コンロは約10年
  - ひとことの「ボンベは1日0.5本（強火約1時間…家族で1週間なら10本前後）」を「ボンベは1人1週間6本（使用期限はおよそ7年）」に直した
  - カセットコンロのプリセットに保存期間10年を付けた（期限の管理の対象になる）
- プリセットを52件追加した（146件）
  - 水: 5L・長期保存水・お茶やスポーツドリンク・給水用ポリタンク
  - 食料: 袋麺・魚の缶詰・パンの缶詰・レトルト丼の素・レトルトおかゆ・スープ・フルーツ缶・ようかん・ナッツ・調味料
  - トイレ・衛生: トイレ用凝固剤（1回分として数える）・防臭袋・ポータブルトイレ・からだふきシート・石けん
  - 明かり・電源: ソーラーランタン・LEDキャンドル・乾電池 単2・充電ケーブル・ポータブル電源・車載用の充電器
  - 調理・熱源: 固形燃料・鍋やかん・クーラーボックス・キッチンばさみ
  - 救急・薬: 胃腸薬・目薬・湿布・冷却シート・三角巾・はさみとピンセット
  - 乳幼児: ミルク用の水・子どもの着替え・おもちゃと絵本
  - 高齢者・介護: 口腔ケア用品・障害者手帳と保険証のコピー
  - ペット: ペット用の水・常備薬・折りたたみ食器・ワクチン証明のコピー
  - その他: エアマット・防寒着とアルミシート・タオル・着替え・耳栓とアイマスク・消火器・養生テープ・バール
- 既存94件の名前・分類・単位・1つあたりの量は変えていない（サンプルデータ・初回設定・保存済みのデータが名前で参照するため）。並び順は分類の中で整理した
- チェックリスト
  - 基本の項目を59 → 61に（在宅避難に「冷蔵庫の中身を把握し、停電したら先に食べる」、情報・連絡に「はぐれた時のために、家族の写真をスマホと紙で持っている」）
  - 世帯別の項目を、在宅避難・家の安全・情報の各リストにも乳幼児・高齢者・ペット向けを1つずつ追加（10 → 19項目。全部該当すると80項目）
  - 既存の項目の文言は変えていない（チェックの保存キーが文言のため）
