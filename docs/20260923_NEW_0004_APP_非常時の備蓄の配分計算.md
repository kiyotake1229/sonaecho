# 非常時の「備蓄の配分」計算（そなえ帳）

- 管理番号: #0004
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）
- 作成日: 2026-09-23
- 関連: #0002（1日の必要量 `rate` を共用）、#0008（ボンベの目安）

## 概要

もしもタブに「備蓄の配分」を追加した。救援や復旧まで何日もたせるか（3・5・7・10・14日）を選ぶと、いまの備蓄で1日に使える量と1人あたりの量を出し、目安（水1人1日3Lなど）に届くかを色で示す。届かないものには節約のコツを添える。平時の備えだけでなく、災害が起きた後にも使う機能。

## 対象ファイル

- `index.html` … `sheetRation`・`rationDays`、もしもタブ `renderSos`（道具に「備蓄の配分」を追加）、CSS `.rt`

## 変更内容

- 1日に使える量 = 備えている量（期限切れを除く）÷ 選んだ日数
- 1人あたり = 1日に使える量 ÷ 人数。おむつは乳幼児の数、ペットフードはペットの数で割る
- 目安以上は緑、目安の半分以上は黄、それ未満は赤の札を付ける
- 目安に届かない分類があれば、分類ごとのコツを出す（飲み水を最優先に、トイレは便器にポリ袋と新聞紙・凝固剤で代用、お湯はまとめて沸かして保温ボトルへ など）
- 最初に選ばれている日数は、世帯設定の目標日数（3日分／1週間分）。備蓄が0件のときは案内だけ出す
- もしもタブの道具を6つから8つにした（「備蓄の配分」「紙に残す」。#0005）。あわせて「集合場所・避難所」の見出しを「集合場所」に短くし、2行に折れないようにした
