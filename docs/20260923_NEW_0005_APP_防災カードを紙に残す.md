# 防災カードを紙に残す（印刷・画像）（そなえ帳）

- 管理番号: #0005
- 種類: NEW（新機能）
- 対象: アプリ本体（APP）、iOSアプリ（IOS）
- 作成日: 2026-09-23
- 関連: #0006（iOS の共有シート）

## 概要

スマホの電池が切れても家族の連絡先などがわかるように、家族カード・集合場所・連絡のとり方（171）・緊急の番号・備蓄の置き場所を、A4 1枚の画像（わが家の防災カード）にまとめる機能を追加した。Web版は印刷（PDF保存も可）と画像の共有、iOS版は共有シートから写真への保存・プリント・送信ができる。画像は端末内の Canvas で描き、外部には何も送らない。

## 対象ファイル

- `index.html` … `sheetPaper`・`paperCanvas`・`printPaper`・`sharePaper`・`paperCv`、印刷用 CSS（`#printArea`、`@media print`）、`.paper-prev`、家族カードのシート（`sheetFamily`）ともしもタブに「紙に残す」、撮影用 `open=papercard`
- `ios-app/package.json`・`ios-app/package-lock.json` … `@capacitor/filesystem`（7.1.8）を追加
- `ios-app/ios/App/Podfile`・`Podfile.lock` … `CapacitorFilesystem`（依存 `IONFilesystemLib` 1.1.4）
- `ios-app/ios/App/App/Info.plist` … `NSPhotoLibraryAddUsageDescription`（「防災カードの画像を写真に保存するために使います。」）
- `tools/take-shots.sh` … カードそのもの（`paper-card.png`）も撮る

## 変更内容

- カードの内容（1240×1754px、A4 縦・150dpi 相当）
  - 見出し: 作成日・人数（ペットの数）
  - 家族の連絡先: 最大6人。名前・続柄・血液型・電話。アレルギー・持病・メモは2行まで
  - はぐれたら: 集合場所①（近く）・②（遠く）・避難所・メモ
  - つながらない時は: 災害用伝言ダイヤル171の録音・再生の手順
  - 緊急の番号: 110・119・171。かかりつけ医・職場の記入欄
  - 備蓄の置き場所: 置き場所ごとに品名と数。品の途中では改行しない。入りきらない分は「ほか◯か所はアプリで確認」
- 登録がない欄は、手書きできる空欄と線を引く（家族3行・備蓄4行）
- Web版
  - 「印刷する」: 画像だけを A4 に印刷する（`window.print`）。印刷の画面で PDF 保存もできる
  - 「画像を共有」: ファイルを共有できるブラウザでは Web Share API で共有
  - どちらも使えないときは、画像の長押し保存を案内する
- iOS版
  - 画像をアプリのキャッシュに書き出し（Filesystem）、共有シート（Share）で開く。共有シートから「画像を保存」「プリント」「メッセージ」などを選べる
  - 写真への保存には `NSPhotoLibraryAddUsageDescription` が要る（ないと保存時にアプリが落ちる）ので Info.plist に追加した
  - Filesystem が使えないとき（`npx cap sync` をしていない等）は長押し保存の案内に切り替える
- プラグインの追加は、Dropbox に `node_modules` を作らないよう作業用のコピーで `npm install` と `npx cap sync ios` を行い、変わった設定ファイルだけを戻した（pod install は Xcode がないため手元では失敗。GitHub Actions で確認する）
