# 岩崎さんへ — 「そなえ帳」iOSアプリ ビルド・申請手順

岩崎さん

家庭の備蓄と防災の手帳アプリ「そなえ帳」のiOSプロジェクトです。
**Xcodeで開いてビルド → App Store申請** まで進められる状態になっています。

必要な作業は大きく2つです。

1. Xcodeで開いて、署名（Team）を自社アカウントに設定してビルド → 3章
2. App Store Connect にアップロードして審査に提出 → 4章

申請時に入力するアプリ名・説明文・キーワードなどは、4章に**下書きを用意してあります**。
そのまま使っていただいても、修正いただいても構いません。

企画の意図やデモの見せ方は、1つ上のフォルダの [岩崎さんへの提案書.md](../岩崎さんへの提案書.md) にまとめてあります。
ご不明な点があればお知らせください。

## 1. アプリ概要

| 項目 | 内容 |
|------|------|
| アプリ名 | そなえ帳 |
| Bundle ID | `work.ltv.sonaecho` （変更する場合は Xcode の Signing & Capabilities で変更できます） |
| 構成 | Capacitor 7（WebView同梱型ネイティブアプリ。通信してWebサイトを表示する作りではありません） |
| 対応 | iPhone（縦画面固定）/ iPad |
| 通信 | **なし**（完全オフライン動作） |
| データ | **端末内のみ**（localStorage＋ネイティブ保存の二重化）。外部送信・収集は一切なし |
| ネイティブ機能 | ローカル通知（期限・点検日）、触覚フィードバック、共有シート（安否連絡・家族カード） |

## 3. ビルド手順

このフォルダ（`ios-app/`）で、以下を順に実行してください。

```bash
# 1) 依存パッケージを取得
npm install

# 2) Web本体をコピーして、iOSプロジェクトに反映（pod install もここで走ります）
npx cap sync ios

# 3) Xcodeで開く
open ios/App/App.xcworkspace
```

> **注意**: 必ず `App.xcworkspace` を開いてください（`App.xcodeproj` ではありません）。

> `pod install` はこちらの環境（Xcode無し）では実行できていません。上記 2) で自動的に実行されます。
> 日本語を含むフォルダ名でエラーになる場合は、先に `export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8` を実行してください。
> 同じ手順で GitHub Actions（macOS）上のビルドが通ることは**確認済み**です（2026-09-14）。結果はリポジトリの Actions タブで見られます。
> https://github.com/kiyotake1229/sonaecho/actions

### Xcode上での設定

1. 左ペインで **App** を選択 → **Signing & Capabilities** タブ
2. **Team** に自社のApple Developerアカウントを選択（"Automatically manage signing" はON）
3. 必要に応じて **Bundle Identifier** を自社のものに変更
4. **General** タブで **Version**（例: 1.0.0）と **Build**（例: 1）を設定

### 動作確認

- 上部のデバイス選択から実機またはシミュレータを選び ▶ で起動
- 設定タブ →「サンプルデータを読み込む」で記入済みの状態を確認できます
- 実機でご確認いただきたい点：触覚、通知（設定 →「通知をテスト」）、もしもタブのホイッスルの音量、安否連絡の「送る」で共有シートが開くこと

## 4. App Store申請

1. Xcode: **Product → Archive**
2. Organizerが開いたら **Distribute App → App Store Connect** でアップロード
3. [App Store Connect](https://appstoreconnect.apple.com) でアプリ情報を入力して審査提出

### 申請情報（下書き）

**アプリ名**
```
そなえ帳 - 備蓄と防災の手帳
```

**サブタイトル（30字以内）**
```
必要量がわかる。期限切れを出さない。
```

**説明文**
```
「そなえ帳」は、家庭の備蓄と防災をひとつにまとめた手帳アプリです。
通信は一切使わず、圏外でも停電でも、端末の中だけで動きます。

■ 必要な量が一目でわかる
家族の人数と「3日分／1週間分」の目標から、水・食料・簡易トイレ・カセットボンベの必要量を自動で計算。いまの備蓄で何日もつか、あと何が足りないかがすぐにわかります。目安は内閣府・農林水産省の家庭備蓄ガイドに基づいています。

■ 期限切れを出さない
賞味期限・使用期限を登録すると、近づいたものを色分けしてお知らせ。「1つ使った」をタップすれば数量が減り、買い足しリストに自動で入ります。ふだん食べて買い足す「ローリングストック」が自然に回ります。

■ 120種類以上のプリセット
水2L、アルファ米、簡易トイレ、乾電池、常備薬、おむつ、ペットフードなど、よくある備蓄をタップするだけで登録。単位や目安の保存期間も入っています。

■ 家族構成に合わせたチェックリスト
非常持ち出し袋、在宅避難の備え、家の安全対策、情報・連絡の備え。乳幼児・高齢者・ペットのいるご家庭では項目が自動で増えます。

■ もしもの時の道具箱（通信不要）
・ライト（画面全体を白く。SOSのモールス点滅つき）
・ホイッスル（大音量で居場所を知らせる）
・家族カード（血液型・アレルギー・持病・連絡先）
・集合場所・避難所のメモ
・安否連絡の定型文（時刻入り。コピーや共有ですぐ送れる）
・災害メモ（時刻つきで記録）
・地震・津波・台風・火災・停電・断水の行動ガイド、災害用伝言ダイヤル171の手順

■ そなえ度
備えの状態を0〜100の「そなえ度」で表示。何をすれば上がるかが内訳でわかります。

■ その他
・期限と年2回の点検日のリマインド通知
・ダークモード対応
・データのバックアップ / 復元
・完全オフライン動作。データは端末内にのみ保存され、外部に送信されません。
```

**キーワード（100字以内・カンマ区切り）**
```
防災,備蓄,ローリングストック,非常食,防災グッズ,賞味期限,地震,台風,停電,断水,避難,持ち出し袋,安否確認,家族,チェックリスト
```

**カテゴリ**
- プライマリ: ライフスタイル
- セカンダリ: ユーティリティ

**年齢制限**: 4+

### プライバシー情報（App Store Connect「App のプライバシー」）

- **データを収集しません** を選択してください。
- 理由: 本アプリは通信機能を持たず、すべてのデータ（備蓄・家族カード・メモ）は端末内にのみ保存されます。アナリティクス・広告・トラッキングは一切ありません。

### サポートURL

```
https://kiyotake1229.github.io/sonaecho/
```

以下のサイズが必要です（シミュレータで撮影）。設定 →「サンプルデータを読み込む」の状態で撮ると見栄えがします。

## 5. 審査で見られやすい点

Appleガイドライン **4.2（最低限の機能）** について、本アプリは以下を満たしています。申請時の備考欄に記載すると安全です。

- 完全オフラインで動作する自立したアプリ（Webサイトの単なる表示ではない）
- 端末内にデータを保存し、継続的に利用する設計（備蓄の登録・期限管理・チェックリスト）
- ネイティブのローカル通知・触覚フィードバック・共有シートを実装

**健康・安全に関する内容について**：行動ガイドは一般的な防災の指針で、アプリ内にも「実際の避難は公的機関の情報を優先してください」と明記しています。医療行為や診断に当たる内容は含みません。

**審査用メモ（備考欄の例）**
```
This app is a fully offline household emergency-preparedness notebook. It calculates required stockpile amounts (water, food, toilet, fuel) from household size based on Japanese Cabinet Office guidelines, tracks expiration dates with local notifications, provides household-specific checklists, and offers offline emergency tools (screen flashlight with SOS blink, whistle sound, family medical card, safety message template). All data is stored on device only; no network requests are made. Native features: local notifications, haptics, share sheet. To see the app populated, open Settings → "サンプルデータを読み込む" (Load sample data).
```

## 6. アプリ内容を修正したい場合

アプリ本体は 1つ上のフォルダの `index.html` です。修正後、このフォルダで：

```bash
npm run sync
```

を実行するとiOSプロジェクトに反映されます。その後Xcodeで再ビルドしてください。
Web版（サポートURL）は `index.html` を GitHub に push すると数分で更新されます。
