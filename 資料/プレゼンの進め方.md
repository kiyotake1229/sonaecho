## 1. 1分版（エレベーターピッチ）

> 今回は、お題をもらってではなく、**テーマ選びから自分で決めて**1本作りました。
> 家庭の備蓄と防災の手帳アプリ「そなえ帳」です。
>
> 国は「最低3日、できれば1週間分」の備蓄を呼びかけていますが、実際には**「何をどれだけ」がわからない**のが一番の壁です。
> このアプリは家族の人数を入れると必要量を計算して、**「いまの備蓄で約1.5日。簡易トイレが先に尽きます」**と言い切ります。
> そのまま「簡易トイレ30回分を買い足しリストへ」と、**次にやることまで1タップ**。期限が近いものは知らせて、期限切れを出さない設計です。
>
> もしもの時は、ライト・家族カード・安否連絡に加えて、**救援まで何日もたせるかの配分計算**や、**紙に残す防災カード**になる。**全部、通信なしで動きます。**
> うちがずっと守ってきた「通信なし・端末内保存」の方針が、防災ではそのまま売りになります。
>
> Web版は公開済み、iOSのプロジェクトも組んであって、申請文面まで下書き済みです。

### 2-1. 導入（1分）

話すこと：
- これまでの5本はお題をもらって作った。今回は「自分ならこれを出す」というテーマで作った
- 選んだ基準は3つ。**需要がある／年2回必ず話題になる／うちの作り方が強みになる**
- 結論から言うと、Web版は完成して公開済み。iOSも申請一歩手前まで来ている

### 2-2. 課題と着眼点（2分）

話すこと：
- 内閣府・農水省は「最低3日、推奨1週間」の家庭備蓄を呼びかけている。水は1人1日3L、トイレは1日5回、カセットボンベは1人1週間6本。**でも1週間分を備えている家庭は少ない**
- 理由は「何をどれだけ買えばいいかわからない」「買っても期限切れにしてしまう」の2つ
- 既存アプリは、自治体アプリ＝情報配信が中心で家庭の備蓄は管理できない。備蓄管理アプリ＝数を数えるだけで、UIが古い・広告が多い・非常時に使う機能がない
- **3月11日と9月1日（防災の日）** に毎年メディアとストアで特集が組まれる。リリースと更新をここに合わせられる

ひとこと添えるなら：
> 「防災は、必要だとみんな分かっているのに動けない領域です。動けない理由を1つずつ消すアプリにしました」

### 2-3. デモ（4分）※台本

**① ホーム（40秒）**
> 「4人家族・3日分の設定です。一番上に**『いまの備蓄で約1.5日』**。水・食料・トイレのうち、一番先に尽きるものの日数です。この家は**簡易トイレが先に尽きます**」
> 「そなえ度は78点で『あと少し』。水かトイレが足りないうちは『安心』にはならない作りです」
> （リングをタップ）「分類ごとに何日もつかも見えます。飲料水2.2日、トイレ1.5日」

**② 次にやること（40秒）**
> 「その下が**次にやること**。点数が上がる順に並んでいます。『簡易トイレをあと30回、＋7点』」
> （タップ）「押すと、**何をいくつ買えばいいかまで計算して**買い足しリストに入ります。間違えても『元に戻す』で戻せます」

**③ 備蓄 → 買い足し → 期限順（1分）**
> 「買い物のときはこのリストを見て、買ったら『備蓄へ』。**期限が違うので、今ある分とは別の行で登録**されます。古い方から使えば、使いきった行は自動で片付きます」
> （期限順を開く）「期限が近い順。カップ麺が期限切れ、30日以内が4点。期限の入力は『今日から1年・3年・5年』のボタンや、まとめて登録で速く入れられます」
> 「期限切れは必要量に数えません。数字がごまかされない作りです」

**④ もしも（1分10秒）**
> 「ここが他のアプリにない部分です。まず**備蓄の配分**。救援まで何日もたせるかを選ぶと、1日に使える量が出ます」（7日を押す）「1週間もたせると、**水は1人1日1Lほど**しか飲めない。だから備えが要る、というのが一目でわかります」
> 「次に**紙に残す**。家族の連絡先・集合場所・171の使い方・備蓄の置き場所が、A4 1枚の防災カードになります」（印刷した紙を見せる）「スマホの電池が切れても、冷蔵庫に貼っておけば家族全員が見られる」
> 「ほかにライト（点けてSOS点滅を見せる）、ホイッスル（音量注意・一瞬だけ）、家族カード、安否連絡の定型文。**平時に入れておくから非常時に使える**。手帳と道具箱を1つにした理由がこれです」

**⑤ 機内モード（30秒）※一番大事**
> 「最後に。（機内モードにする）このまま全部やり直しても、全部動きます。**通信を一切使っていないので、圏外でも停電でもサーバーが落ちても開ける。** これは防災アプリとしていちばん大事な性能だと思っています」

### 2-4. 何が違うのか（1分）

3つに絞って言う：
1. **「何日もつか」と「次に何を買うか」まで示す**（数を数えるだけのアプリとの違い）
2. **期限切れを出さない設計**（使う → 買い足す → 期限ごとに登録、が一周する）
3. **平時と非常時をひとつのアプリで**（配分計算と紙の防災カードまで）、しかも通信なし

### 2-5. 展開と収益（1分）

- **無料版（今回）**：無料・広告なし。防災の日／3.11に合わせて出し、レビューと利用状況を見る
- **プラス（買い切り）**：480円程度。バーコード登録、家族間のQR共有（通信なしのまま）、複数の備蓄場所、CSV書き出し
- **法人向け**：企業・オフィスの備蓄管理モード。東京都は条例で事業者に3日分の備蓄を努力義務にしている。総務・防災担当が対象。自治体・保険会社・防災用品メーカーへのOEMも考えられる

ひとこと：
> 「まず無料で『防災』カテゴリでの評価を作って、法人向けを次の柱にする順番で考えています。防災カードは、自治体や企業と組むときの分かりやすい入口にもなります」

### 2-6. 現在の状態とお願い（1分）

- Web版：完成・公開済み（v1.1.0。 https://kiyotake1229.github.io/sonaecho/ ）
- iOS：Capacitorで構築済み。手元にXcodeがないので GitHub のmacOS環境でビルドが通ることまで確認
- 申請文面（アプリ名・説明・キーワード・カテゴリ・プライバシー・審査用の英文備考）は下書き済み。v1.1 の機能も反映済み
- 変更ごとの記録を `docs/` に残している（#0001〜#0009）
- **お願いしたいこと**：
  1. Xcodeのある環境で `npm install` → `npx cap sync ios` → 実機で動作確認（触覚・通知・音量・共有シート・防災カードの保存）
  2. Apple Developer Program の手配
  3. 問題なければ「コツコツ」と同じ流れで申請

## 3. 想定質問と答え

| 質問 | 答え |
|---|---|
| 競合はいないの？ | 備蓄管理アプリ自体はある。ただ「何日もつか・次に何を買うか」「使う→買い足すの一周」「非常時の道具箱と紙の防災カード」を通信なしで揃えたものは見当たらない。自治体アプリは情報配信が中心で補完関係 |
| 必要量の根拠は？ | 農水省「家庭備蓄ポータル」（災害時に備えた食品ストックガイド）と内閣府の防災情報。水3L／食3食／トイレ5回／ボンベ1人1週間6本、最低3日・推奨1週間。アプリ内にも出典を明記 |
| 「何日もつか」はどう計算している？ | 備えている量 ÷ 1日に必要な量。水・主食・簡易トイレのうち一番短いもの。期限切れは数えない |
| 行動ガイドの内容は大丈夫？責任は？ | 一般的な防災指針の範囲。医療・診断に当たる内容は入れていない。アプリ内に「実際の避難は公的機関の情報を優先」と明記。審査対策にもなる |
| 通知はWeb版でも届く？ | Web版はアプリを開いたときのお知らせのみ。iOS版はローカル通知で閉じていても届く（期限N日前、年2回の点検日） |
| データはどこに？ | 端末内のみ。通信ゼロ。家族カードのような個人情報こそ端末外に出さない設計。防災カードの画像も端末の中で作る。App Storeのプライバシーは「収集しません」 |
| 機種変更したら？ | 設定のバックアップで文字列をコピー／共有して復元。有料の「プラス」でQRコードによる家族間共有も検討 |
| 審査4.2（WebViewだけのアプリ）は？ | 完全オフライン・端末内保存・継続利用の設計に加え、ローカル通知・触覚・共有シート（文章と画像）を実装。コツコツと同じ根拠で通せる |
| どれくらいで作った？ | v1.0 は企画から文書まで1日、v1.1 の改善も1日。単一HTML約160KB、外部ライブラリなし |
| Android は？ | Web版（PWA）がそのまま動く。ストア配布が必要なら Capacitor で Android も生成できる |
| 法人向けは本当に需要ある？ | 東京都帰宅困難者対策条例で従業員3日分の備蓄が努力義務。総務担当は表計算で管理しているケースが多く、複数拠点・点検記録・期限一覧が欲しいという声が典型。まず個人版で実績を作ってから提案する |
| 収益化で広告は？ | 入れない方針。非常時に開くアプリに広告は合わないし、通信なしの方針とも矛盾する。買い切りと法人向けで回収 |

## 4. 話し方のコツ

- 最初の1分で「自分で選んだテーマ」「完成している」「通信なしが強み」の3点を言い切る
- デモは**スマホを持って操作しながら**話す。提案書ページは補助で、読み上げない
- 「いまの備蓄で約1.5日 → 次にやることを1タップ」「紙の防災カード」「機内モードで全部動く」の3か所は必ず見せる。時間がなければ他は削る
- 数字は3つまで（1.5日／3日→1週間／水3L）。多く言わない
- 最後は「お願いしたいこと」を1〜3で具体的に言って終わる
