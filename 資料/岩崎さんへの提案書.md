## 1. なぜこのテーマか

| 観点 | 内容 |
|---|---|
| **社会的な需要** | 内閣府・農水省は「最低3日、推奨1週間」の家庭備蓄を呼びかけているが、実際に1週間分を備えている家庭は少ない。「何をどれだけ」がわからないことが最大の壁 |
| **年2回の確実な追い風** | 3月11日と9月1日（防災の日）に必ず話題になる。メディア露出・ストア特集・自治体の啓発と時期が重なる |
| **うちの開発方針がそのまま強みになる** | これまで全アプリ「通信なし・端末内保存」で作ってきた。防災アプリでは**それ自体が価値**（圏外・停電・サーバー障害でも動く） |
| **既存アプリとの補完** | ゲーム3本・学習1本・習慣1本に対し、生活実用の1本。ポートフォリオの幅が広がる |
| **競合の状況** | 自治体アプリは「情報配信」が中心で、家庭の備蓄管理は弱い。備蓄管理アプリは存在するが、UIが古い・広告が多い・「もしもの時に使う道具」がないものがほとんど |

## 2. 何が違うのか（3つの差別化）

1. **「何日もつか」と「次に何を買うか」まで示す**
   人数×日数から必要量を計算し、「いまの備蓄で約1.5日。簡易トイレが先に尽きます」と言い切る。さらに「簡易トイレ ×30回分を買い足しリストへ（そなえ度 ＋7点）」と、次の行動まで1タップでつなぐ。数を数えるだけのアプリと違い、行動につながる。
2. **期限切れを出さない設計**
   期限は「今日から1年・3年・5年」のボタンとまとめ登録で素早く入る。「1つ使った」→ 買い足しリスト →「備蓄へ」で、買った分は期限ごとに別の行（ロット）で管理し、使いきった古い行は自動で片付く。ローリングストックの一周がアプリの中で完結する。
3. **平時と非常時をひとつのアプリで**
   ふだんは備蓄の手帳、もしもの時はライト・ホイッスル・家族カード・安否連絡・行動ガイドに加え、**備蓄の配分**（救援まで何日もたせるかを選ぶと1日に使える量がわかる）と、**紙に残す防災カード**（家族の連絡先・集合場所・171・備蓄の置き場所をA4 1枚に）。**すべて通信なし**で動く。家族カードや防災カードは、平時に作っておくからこそ非常時に使える。

## 3. 主な機能

- **ホーム**：いまの備蓄で何日すごせるか、次にやること（そなえ度が上がる順）、足りない分をまとめて買い足しリストへ
- **そなえ度**（0〜100）：充足率・持ち出し袋・連絡の備え・期限管理から算出。水・食料・トイレが目標に届くまでは段階が「あと少し」まで
- **備蓄管理**：146種類のプリセット、期限の色分けとまとめ登録、分類ごと／置き場所ごと、期限順、買い足しリスト、元に戻す
- **チェックリスト**：4リスト・基本61項目。乳幼児・高齢者・ペットの有無で各リストの項目が増える（最大80項目）
- **もしもの道具箱**：ライト（SOS点滅）、ホイッスル（音源不要の合成音）、家族カード、集合場所、安否連絡、災害メモ、備蓄の配分、紙に残す防災カード、行動ガイド（6災害）、171の手順
- **通知**（iOS版）：期限N日前、年2回の点検日
- ダークモード、バックアップ/復元、サンプルデータ（表示中は「自分の記録を始める」で切り替え）

## 4. 収益・展開の案

| 段階 | 内容 |
|---|---|
| **無料版（今回。v1.1）** | 無料・広告なしで公開。防災の日（9/1）・3/11 に合わせた露出を狙う。レビューと利用状況を見る |
| **プラス（買い切り）** | 例：480円。バーコード登録、家族間のQRコード共有（通信なしのまま）、複数の備蓄場所（自宅・車・職場）、CSV書き出し |
| **法人向け** | **企業・オフィスの備蓄管理**モード（従業員数ベースの必要量、複数拠点、点検記録）。東京都は条例で事業者に3日分の備蓄を努力義務としており、総務・防災担当の需要がある。自治体・保険会社・防災用品メーカーへのOEM／タイアップも考えられる |

まずは無料で出して「防災」カテゴリでの評価を作り、法人向けを次の柱にする、という順番を考えています。
防災カードは「紙に残す」という分かりやすい価値があり、防災の日の話題づくりや、自治体・企業との連携の入口にも使えます。

## 5. 5分でデモするときの順番

1. **サンプル入りで開く**（`?demo=1` のURL、または 設定 →「サンプルデータを読み込む」。4人世帯・子ども/高齢者/ペットあり・27点登録済み）
2. **ホーム**：「いまの備蓄で約1.5日。簡易トイレが先に尽きます」。そなえ度78・「あと少し」。リングをタップして、分類ごとの「何日もつか」を見せる
3. **次にやること**：「簡易トイレをあと30回 ＋7点」をタップ → 買い足しリストに「簡易トイレ 30回分」が入る（元に戻すも見せる）
4. **備蓄 → 買い足し →「備蓄へ」**：期限が違うので別の行で登録される。**期限順**では期限切れのカップ麺と、30日以内の4点
5. **もしも**：「備蓄の配分」で7日にすると1人あたりの水が目安を大きく下回る → 「紙に残す」で防災カード（A4 1枚）を見せる。ライト→SOS点滅、ホイッスル（音量注意）
6. **機内モードにして同じ操作**：すべて動くことを見せる（ここが一番伝わる）
