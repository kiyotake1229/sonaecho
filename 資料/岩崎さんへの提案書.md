## 1. なぜこのテーマか

| 観点 | 内容 |
|---|---|
| **社会的な需要** | 内閣府・農水省は「最低3日、推奨1週間」の家庭備蓄を呼びかけているが、実際に1週間分を備えている家庭は少ない。「何をどれだけ」がわからないことが最大の壁 |
| **年2回の確実な追い風** | 3月11日と9月1日（防災の日）に必ず話題になる。メディア露出・ストア特集・自治体の啓発と時期が重なる |
| **うちの開発方針がそのまま強みになる** | これまで全アプリ「通信なし・端末内保存」で作ってきた。防災アプリでは**それ自体が価値**（圏外・停電・サーバー障害でも動く） |
| **既存アプリとの補完** | ゲーム3本・学習1本・習慣1本に対し、生活実用の1本。ポートフォリオの幅が広がる |
| **競合の状況** | 自治体アプリは「情報配信」が中心で、家庭の備蓄管理は弱い。備蓄管理アプリは存在するが、UIが古い・広告が多い・「もしもの時に使う道具」がないものがほとんど |

## 2. 何が違うのか（3つの差別化）

1. **必要量から逆算する**
   人数×日数から必要量を自動計算し、「あと水9L・トイレ30回」と具体的に示す。数を数えるだけのアプリと違い、行動につながる。
2. **期限切れを出さない設計**
   「1つ使った」→買い足しリストへ→「備蓄へ」で戻す。ローリングストックの一連の流れをアプリの中で完結させた。
3. **平時と非常時をひとつのアプリで**
   ふだんは備蓄の手帳、もしもの時はライト・ホイッスル・家族カード・安否連絡・行動ガイドの道具箱。**すべて通信なし**で動く。家族カードや安否連絡の定型文は、平時に入れておくからこそ非常時に使える。

## 3. 主な機能

- **そなえ度**（0〜100）：充足率・チェックリスト・連絡の備え・期限管理から算出。内訳で「何をすれば上がるか」がわかる
- **備蓄管理**：120種類以上のプリセット、期限の色分け、分類フィルタ、期限順、買い足しリスト
- **チェックリスト**：4リスト・60項目超。乳幼児・高齢者・ペットの有無で項目が変わる
- **もしもの道具箱**：ライト（SOS点滅）、ホイッスル（音源不要の合成音）、家族カード、集合場所、安否連絡、災害メモ、行動ガイド（6災害）、171の手順
- **通知**（iOS版）：期限N日前、年2回の点検日
- ダークモード、バックアップ/復元、サンプルデータ

## 4. 収益・展開の案

| 段階 | 内容 |
|---|---|
| **v1.0（今回）** | 無料・広告なしで公開。防災の日（9/1）・3/11 に合わせた露出を狙う。レビューと利用状況を見る |
| **v1.1** | 買い切りの「プラス」（例：480円）：バーコード登録、家族間のQRコード共有（通信なしのまま）、複数の備蓄場所（自宅・車・職場）、CSV書き出し |
| **法人向け** | **企業・オフィスの備蓄管理**モード（従業員数ベースの必要量、複数拠点、点検記録）。東京都は条例で事業者に3日分の備蓄を努力義務としており、総務・防災担当の需要がある。自治体・保険会社・防災用品メーカーへのOEM／タイアップも考えられる |

まずは無料で出して「防災」カテゴリでの評価を作り、法人向けを次の柱にする、という順番を考えています。

## 5. 5分でデモするときの順番

1. **設定 →「サンプルデータを読み込む」**（4人世帯・子ども/高齢者/ペットあり・27点登録済みの状態になる）
2. **ホーム**：そなえ度80・「安心」。バーで「飲料水あと9L、トイレあと30回」が見える → リングをタップして内訳
3. **備蓄 → 期限順**：期限切れのカップ麺、30日以内の4点。カップ麺をタップ →「1個使った」→ 買い足しリストに入る
4. **チェック**：非常持ち出し袋を開く。ペット・高齢者の項目が入っていることを見せる
5. **もしも**：ライト→SOS点滅、ホイッスル（音量注意）、家族カード、安否連絡の定型文→「送る」
6. **機内モードにして同じ操作**：すべて動くことを見せる（ここが一番伝わる）

- 期間：1日（企画・設計・実装・ドキュメント）
- 単一HTML（約125KB）、外部ライブラリなし、音源・画像ファイルなし（アイコンはSVG、音はWeb Audioで合成）
